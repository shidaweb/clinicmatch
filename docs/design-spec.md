## 0. 絶対ルール（最初に読む）

1. **URLは1本も変更しない。** 既存パス（`/`, `/cases`, `/cases/[slug]`, `/categories/[slug]`, `/contact`, `/contact/sell`, `/contact/buy`, `/blog`, `/about`, `/terms`, `/privacy`）をそのまま使う。リダイレクト・パス追加・パス改名は禁止。
2. **英語の見出し（MARKETPLACE / CONSULT / CATEGORY / PICO LASER 等）は全廃。** 見出しは**日本語**にし、各ページの主見出しは **`<h1>`** にする。装飾目的の英字eyebrowは置かない。
3. **1ページ＝H1は1つだけ。** H1は日本語で、そのページの内容を表す（SEOの主見出し）。以降は h2 → h3 → h4 の順で、レベルを飛ばさない。
4. デザインは**第2章トークン**に集約。色・余白・角丸・影をトークン外で勝手に作らない。
5. トーンは**美容医療**（医療の信頼感 × 女性的な上品さ）。原色の青・オレンジは使わず、くすみカラー＋明朝見出しで統一。

## 1. デザイン原則

- **エレガント／クリーン／あたたかい仲介。** ハイブランド化粧品LPと医療サイトの中間。
- 余白を広く、罫線は細く、角丸は大きめ、影は淡く。
- **見出しは明朝**（品格）、本文はゴシック（可読性）。
- 匿名・仲介・「連絡先は合意後開示」を一貫して明示し、安心を担保。
- 機器は**比較しやすさ**最優先（スペックを横並びで読める）。

> 文字色は背景と同系の濃いトーンを使い、純黒（#000）・原色は使わない。

### 2.2 タイポグラフィ
- **見出し（serif）**：`Shippori Mincho`（フォールバック `"Noto Serif JP", serif`）。
- **本文（sans）**：`Noto Sans JP`（フォールバック `system-ui, sans-serif`）。
- 数字（価格・年式・件数）は**明朝**で表示し、商品然とした上品さを出す。

| 役割 | 要素 | サイズ(PC/SP) | 太さ | 行間 | 字間 | 書体 |
|---|---|---|---|---|---|---|
| ページ主見出し | `h1` | 32 / 26px | 600 | 1.45 | .02em | 明朝 |
| セクション見出し | `h2` | 24 / 21px | 600 | 1.5 | .02em | 明朝 |
| 小見出し | `h3` | 18 / 17px | 600 | 1.6 | .01em | 明朝 |
| ラベル/カード見出し | `h4` | 15px | 700 | 1.6 | 0 | ゴシック |
| 本文 | `p` | 16 / 15px | 400 | 1.8 | .01em | ゴシック |
| 補助 | `small` | 12–13px | 400 | 1.7 | 0 | ゴシック |

### 2.3 スペーシング / レイアウト
- スケール：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px。
- コンテンツ最大幅：`1080px`（中央寄せ、左右パディング 16px）。
- セクション縦余白：PC `64px`、SP `40px`。
- グリッドgap：カード `16–20px`、フォーム要素 `12px`。

### 2.4 角丸・影・罫線
- 角丸：カード `16px`、入力/小要素 `10px`、**ボタンはピル `999px`**、タグ `999px`。
- 影：通常 `none`、ホバー時のみ `0 10px 26px rgba(70,52,58,.10)`。
- 罫線：`1px solid var(--line)`。区切りも同色ヘアライン。

### 2.5 ブレークポイント
- `sm < 640px`（モバイル：1カラム、下部固定バー）
- `md 640–1024px`（タブレット：2カラム）
- `lg ≥ 1024px`（PC：フィルタ左固定・3〜4カラム）

### 2.7 磨き込み（エディトリアル仕上げ）★必須トーン
汎用的なフラット／管理画面っぽさを避け、上質なエディトリアルに仕上げるための共通ルール。実画面は `clinicmatch_polished.html` / `clinicmatch_polished_pages.html` を基準とする。

- **キッカー＋金のヘアライン**：見出しの上に「`—（金1px・幅36px） 日本語の小ラベル`」を置く。小ラベルは `letter-spacing:.32em`・色 `gold`・11px。**見出しレベルにはしない**（`<p>`）。中央寄せ時は両側に金ライン。
- **明朝の数字**：価格・年式・件数・ステップ番号（01/02/03）はすべて明朝。商品然とさせない。
- **スタッツは細い縦罫で区切る**：数値（明朝・大）＋小ラベル（字間広め）を `1px var(--line)` の縦罫で並べる（ボックス背景は付けない）。
- **ヒーローはエディトリアル**：左にテキスト、右に画像フレーム（`inset:16px` の内側1px白罫＋角丸）。画像に重ねて**浮遊カード**（新着など）を `box-shadow:float` で配置し奥行きを出す。
- **検索バーは浮かせる**：白・ピル・`box-shadow:soft`、セクション境界に半分かかるように `margin-top:-8px`。
- **カードは内側フレーム＋ホバーで持ち上げ**：画像帯に `inset:11px` の白半透明1px罫。`hover` で `translateY(-3px)` ＋ `box-shadow:lift`。
- **行リスト（/cases）はミドルドット区切り**：スペックを「ピコ・2022年・状態良好・保守あり・東京都渋谷区」のように `・`（色 `#D8C6BF`）で繋ぐ。`hover` で持ち上げ。
- **ステップは番号主導**：`01/02/03`（明朝・gold）＋短い見出し＋一言。線で繋がず余白で見せる。
- **罫線で締める**：箱を多用せず、ヘアライン罫と余白で構造を作る。影は通常オフ、ホバー/浮遊要素のみ。
- **フッターは深いプラム**：`plum` 地に多段カラム＋ロゴ明朝。コピーライトは上部に細罫。

## 3. 見出しルール（英語廃止・日本語H1）

- **各ページの主見出しを日本語の `<h1>` にする。** 旧デザインの英語eyebrow（MARKETPLACE 等）は削除。
- 装飾の英字を置きたい場合でも、**H1は日本語**であること（英字はあくまで `<p>` の装飾で、見出しレベルにしない。原則は置かない）。

各ページの H1（確定）：

| URL | H1（日本語） |
|---|---|
| `/` | クリニックマッチ｜美容医療機器の中古売買マーケット（または「美容医療機器の、次の場所を見つける」） |
| `/cases` | 在庫・取引事例をさがす |
| `/cases/[slug]` | （機器名）例：ピコシュア |
| `/categories/[slug]` | （カテゴリ名・日本語）例：ピコレーザー |
| `/contact` | 出品・購入を相談する |
| `/contact/sell` | 売りたい機器を登録・相談する |
| `/contact/buy` | 買いたい機器を登録・相談する |
| `/blog` | ブログ |
| `/about` | 運営会社について |

> 旧「PICO LASER」「CATEGORY」等は、`/categories/[slug]` では日本語カテゴリ名H1に、`/cases/[slug]` では機器名H1に置換。セクション内見出しも英語をやめ、日本語h2/h3にする（例：「スペック」「保守・付属品」「この先の進め方」「このカテゴリの在庫」など）。

## 4. コンポーネント定義（状態を含む）

各コンポーネントはアクセシブルな素のHTML＋Tailwindクラスで実装。色はトークン参照。

### 4.1 ボタン `Button`
- 形：ピル（`rounded-pill`）、パディング `12px 26px`、文字14px/500。
- 種別：
  - `primary`：地 `rose` / 文字 白 / hover `rose.deep`。
  - `secondary`：地 白 / 枠 `#D9B8AF` / 文字 `rose.deep` / hover 地 `blush`。
  - `dark`：地 `plum` / 文字 白（検索など）。
  - `ghost`：地 透明 / 文字 `plum.soft` / hover 下線。
- 状態：`hover`（地/枠を1段濃く）、`active`（`scale(.98)`）、`disabled`（`opacity:.5; cursor:not-allowed`）、`focus-visible`（`outline: 2px solid rose.deep; offset 2px`）。
- アイコンは Tabler outline、左に16–18px。

### 4.2 タグ / バッジ
- タグ（種別）：`rounded-pill`、11px/700、第2.1のタグ配色。位置はカード左上 or 行頭。
- 安心バッジ（保守あり/引継ぎ可/審査済）：11px/500、sage/gold/グレー系。
- 1要素に付けるバッジは最大3つまで。

### 4.3 行リスト項目 `PostRow`（/cases の主役）
- 1行＝1件。左からサムネ(70×54)→[種別タグ＋機器名(h4)]→スペック列(年式/状態/保守/エリア)→右に価格(明朝)＋「詳細 →」。
- hover：背景 `#FFFCFA`＋淡い影。行全体がリンク。
- 「買いたい」行は価格の代わりに「提案する →」。
- レスポンシブ：SPはサムネ上・情報下の積み重ね。

### 4.4 カード `PostCard`（トップの新着等）
- 白地・`rounded-card`・枠 `line`。画像帯(96px)＋本文(型番h4・サブ・バッジ・価格・所在地)。hoverで浮く。

### 4.5 フィルタ `Filters`
- PC：左カラム固定（幅180px）。各項目はピル/セレクト。
- SP：上部「絞り込み」ボタン → ボトムシート（全画面）。
- 選択中はチップ表示＋「クリア」。

### 4.6 フォーム / ステッパー `StepForm`（磨き込み）
- **2カラム構成**：左に入力フィールド、右に「安心パネル」（`blush`地・角丸14px）。安心パネルは「クリニック名は非公開（匿名）／登録は法人番号のみ／連絡先は合意後に開示」をアイコン付きで提示（買い側は「該当機器を持つ売り手から提案が届く」等に差し替え）。SPは縦積み。
- **進捗インジケータ**：左に**明朝の大きなステップ番号**「02」＋「/ 03」、右に細いセグメントバー（完了=`rose-deep`、未完=`line`、高さ3px）、右端に「約2分」。
- 入力：高さ44px、`rounded-[10px]`、枠 `line`、`label`は上に小さく（`plum-soft`）、focusで枠 `rose`＋淡いリング。プレースホルダは `muted`。
- カテゴリは**選択ピル**（選択=`rose-deep`塗り／未選択=白＋細枠）。必須は `*`（くすみ赤 `#B5524E`）。
- 下部に「戻る（`btn-out`）／次へ（`btn-rose`・幅広）」。SPは画面下に固定。
- 法人番号は13桁の数値バリデーション（システム仕様準拠）。
- 完了画面：明朝見出し＋「次にやること（運営から連絡／LINE登録）」を提示。

### 4.7 ヘッダー `GlobalHeader`
- 左：ロゴ（明朝ロゴタイプ＋丸アイコン）。右：さがす／売りたい／買いたい／相談（rose強調）／ブログ／ログイン。
- 半透明白＋下ヘアライン、スクロール追従（sticky）。

### 4.8 フッター `GlobalFooter`
- 地 `plum`・文字 `#D8C4BD`。サービス概要／取扱機器（カテゴリ）／お問い合わせ／会社概要・規約。LINE導線。

### 4.9 モバイル下部バー `BottomActionBar`
- 固定。さがす／出す／**相談**／マイページ。アイコン＋ラベル。

### 4.10 相談CTA `ConsultBlock`
- 帯（地 `blush`）：日本語見出し（h2）「写真と型番だけでも、まずは相談。」＋ `primary` ボタン「出品・購入を相談する」＋一言（匿名・約2分）。
- 各ページ下部・/cases リスト内（破線カード）・詳細サイドに設置。

### 4.11 信頼バンド `TrustBar`
- 4枠：運営が仲介／匿名で相談OK／累計◯件／法人確認。アイコン＋短文。

### 4.12 その他
- パンくず：`muted`、区切り `›`。
- ページネーション：`‹ 1 2 3 ›`、現在地は `rose`。
- 空状態 `EmptyState`：アイコン＋「条件を相談する」CTA。

## 5. ページ別 実装仕様（URL維持・H1日本語）

> 各ページ上部に `GlobalHeader`、下部に `ConsultBlock`＋`GlobalFooter`、SPは `BottomActionBar`。

### 5.1 `/`（トップ）
- **H1（日本語・明朝）**：「美容医療機器の、次の場所を見つける」。直下にリード文（p）。
- セクション順：ヒーロー（H1＋リード＋ボタン2つ：機器をさがす / 出品・購入を相談する＋スタッツ3） → 検索バー（カテゴリ/キーワード/エリア/検索） → h2「新着の在庫」カード列 → h2「取引の進め方」3ステップ → `TrustBar` → h2「カテゴリから探す」6枠（→ /categories/*） → `ConsultBlock` → フッター。
- 英字eyebrowは置かない。

### 5.2 `/cases`（マーケット兼事例。`?category=` 継続）
- **H1**：「在庫・取引事例をさがす」。
- 直下に**タブ（h2相当のUI、見出しはvisually）**：在庫（売り）／買いたい／成約事例（件数併記、デフォルト「在庫」）。
- レイアウト：左 `Filters`（PC固定／SPシート）＋右 `PostRow` リスト。ツールバー（件数・並び替え）。
- リスト内に破線の相談行。下部ページネーション。
- カードでなく**行リスト**で実装（スペック横並び比較）。

### 5.3 `/cases/[slug]`（機器詳細）
- **H1**：機器名（例「ピコシュア」）。英字「PICO LASER」は廃止。
- 上段2カラム：左=画像ギャラリー／右=所在地（匿名）・安心バッジ・希望価格カード・CTA（関心あり／この件を相談する）＋「匿名・連絡先は合意後開示」注記。
- h2「スペック」／h2「保守・付属品」（2カラム表）＋「保守・付属品を質問（匿名Q&A）」。
- h2「この先の進め方」：関心/相談→運営が仲介→合意→連絡先→相対契約（4ステップ）。
- h2「関連の在庫」。

### 5.4 `/categories/[slug]`（カテゴリLP・SEO入口）
- **H1**：日本語カテゴリ名（例「ピコレーザー」）。英字「CATEGORY」廃止。
- ヒーロー（H1＋既存SEO本文p） → h2「このカテゴリの在庫」（カード数枚＋「/cases?category=… で見る」） → h2「読み物」（相場・見極め＋ブログ内部リンク）。

### 5.5 `/contact`（相談ハブ）
- **H1**：「出品・購入を相談する」。英字「CONSULT」廃止。
- リード「匿名OK・約2分。運営があいだに入ります」。
- 3択カード：出品を相談（rose）／購入を相談（sage）／その他（gold） ＋ LINEボタン。各カードは /contact/sell・/contact/buy・LINEへ。

### 5.6 `/contact/sell`（売りたい登録・相談）
- **H1**：「売りたい機器を登録・相談する」。
- `StepForm`（3ステップ＋所要時間）。入力：カテゴリ→メーカー/型番→製造年→**保守状況**→付属品→**所在地（都道府県/市区町村）**→希望価格。完了画面で「次にやること」。

### 5.7 `/contact/buy`（買いたい登録・相談）
- **H1**：「買いたい機器を登録・相談する」。
- `StepForm`。入力：カテゴリ→希望条件→**予算**→希望時期→希望エリア（都道府県/市区町村）。

### 5.8 `/blog` `/about` `/terms` `/privacy`
- **H1**：それぞれ日本語（ブログ／運営会社について／利用規約／プライバシーポリシー）。
- 本文・URL維持。`GlobalHeader/Footer`・トークン・明朝見出しのみ適用。記事末から在庫・相談へ内部リンク。

## 6. レスポンシブ指針
- SP：1カラム、`BottomActionBar` 固定、詳細は価格＋CTAを画面下に固定、フィルタはボトムシート。
- PC：`/cases` は左フィルタ固定、リストは全幅行。トップのカード列は4列→SP横スクロール。
- H1サイズはPC/SPで第2.2の値に切替。

## 7. アクセシビリティ
- H1は各ページ1つ、見出しレベルを飛ばさない。
- 文字色と背景のコントラストはWCAG AA以上（`plum` on `cream` 等で確保。`muted`は補助のみ）。
- ボタン/リンクに `focus-visible` リング。アイコンのみのボタンは `aria-label`。
- フォームは `label` 紐付け、エラーは色＋テキストで明示。

## 8. 実装メモ
- Astro＋Tailwind。フォントは第2.2の `<link>`。アイコンは Tabler outline（webfont）。
- 既存ページは静的維持（SEO温存）。`/cases` 一覧・詳細のみ動的（システム仕様 `docs/spec.md` 準拠）。
- **URLは不変。`/listings` 等の新規パスを作らない。** マーケット＝`/cases`（`?category=`）、相談/登録＝`/contact`系。
- 旧 `/cases` の静的事例は同URLの「成約事例」タブへ移すだけ（被リンク維持）。
