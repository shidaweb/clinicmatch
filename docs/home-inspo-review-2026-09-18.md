# トップページのデザイン・コピー見直し

## 参考

Inspo の recommend と search_screens を実行し、以下の get_screen で保存された画面を確認した。

- Fellow（https://fellowproducts.com）：主役を絞る構成、落ち着いた色と余白。
- ferm LIVING（https://fermliving.com）：商品名と補足情報の強弱、抑えた操作部品。
- Brethren Design Co.（https://www.brethrendesignco.com/shop）：分類と一覧を区切る構成。強い配色・書体は採用しない。

remove-ai-web-style と natural-japanese-writing を併用。既存の明朝・ゴシック、アイボリーとローズのブランドを保つ。

## 変更

ヒーローは「導入したい一台も、手放したい一台も。」とし、買い手と売り手それぞれの利用場面を示す。運営仲介の説明を続け、売却相談リンクと機器検索を並べた。
検索は常時表示のラベルを付け、種別・メーカー／機種名・カテゴリ・エリア・検索ボタンの順に配置した。既存の検索先とパラメータを維持。
成約事例は独立した一覧にし、機種名、メーカー、価格帯、成約時期を比較できるようにした。固定値の累計38件・平均14日を先頭の訴求から外し、既存事例の内容と掲載件数を表示する。

## 写真の追加方針

写真なしで利用できる構成として実装した。既存の施術写真や相談風景は機器の売買を直接示さないため追加しない。
今後の候補は、掲載許可のある実機の全景と、クリニック内の設置風景。横長・長辺1600px以上を目安とし、人物・患者情報や書き込み文字が入らないもの。写真に写る機種の在庫・保証・検品状況は推測して記載しない。

## 確認

- 1280px・768px・390pxでレイアウトを確認。768pxと390pxでページの横はみ出しなし。
- メーカー／機種名と都道府県を指定し、案件一覧へ検索条件が引き継がれることをブラウザーで確認。
- 変更ファイルの ESLint、production build 成功。バックエンド変更なし。
- 全体の型チェックには前回報告済みの既存エラーがあり、本変更では対象外。
